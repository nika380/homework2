## Формат входных данных (`results.txt`)
Текстовый файл содержит до 100 записей. Каждая запись состоит из двух целых чисел, разделённых пробелом или переводом строки:
* `id` — уникальный код от `1` до `9999`
* `score` — балл от `0` до `100`

### Ограничение учебного числового ввода
Все вводимые числовые значения должны помещаться в стандартный тип `int` и не содержать посторонних символов (разбор чисел за пределами `int` и смешанных строк вроде `12abc` не поддерживается). При вводе букв вместо команды меню или `id` программа выводит `Input error` и завершает работу.

## Команды меню
* `1` — показать все загруженные записи в исходном порядке
* `2` — вывести статистику (количество, средний балл, количество сдавших `>= 60`, минимум и максимум)
* `3` — найти запись по введённому `id`
* `4` — выполнить индивидуальный вариант (вывести записи с нечётным `id`)
* `5` — сохранить текущий список в файл `report.txt`
* `0` — выход из программы

> **Внимание:** При выборе команды `5` файл `report.txt` каждый раз полностью перезаписывается.

## Основные функции программы
* `load_results()` — чтение и валидация данных из `results.txt`
* `is_duplicate_id()` — проверка уникальности кода студента
* `show_results()` — вывод таблицы результатов на экран
* `show_statistics()` — расчёт статистики без деления на ноль
* `find_result()` — линейный поиск записи по `id`
* `individual_variant()` — фильтрация записей с нечётным `id`
* `save_results()` — сохранение данных в `report.txt`
